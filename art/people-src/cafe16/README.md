# Café 16 source models

16 individually generated transparent PNGs, numbered to match the requested list. Original generated artwork is preserved without resampling, recoloring or anatomy edits. PROMPTS.md contains the shared rules in full for every image and the regeneration clarification used for image 12.

These are flattened standing source poses for your existing rig, not animation frames or extracted modular layers. Man source canvases are 1199×1312; woman source canvases are 1070×1470. Actual character bounds are recorded in manifest.json using alpha greater than 32 to ignore faint stray pixels. Fit the artwork to your existing importer scale and ground anchor. The preview alone uses nearest-neighbor scaling for comparison. No rig code was changed.

The requested set consists of tee three-quarter front/back plus jacket/tee south, north and east for each person. It is not a complete separately drawn eight-direction set: your existing diagonal jacket art and planned mirroring supply remaining directions. Mirroring switches the mug hand.

Review: all PNGs decoded successfully, have real transparency, and contain the full visible character with a margin. Every generation was visually reviewed. Image 12 was regenerated to hide her face and mug in the north view. Exact anatomical registration, palette equivalence and camera matching are not guaranteed by generation.
