# Archive

Retired art, kept for reference. Nothing here is served by the site.

- `old-cafe/`: the first café, converted from a generated image. Background, 19 cut-out
  sprites, and the scripts that cut them (`cut_assets.py`) and painted them out
  (`empty_room.py`). Replaced by the hand-drawn isometric room.
- `three-quarter-view/`: the first batch of hand-drawn assets in 3/4 top-down view
  (`draw_assets.py`). Replaced by the isometric set in `art/draw_iso.py`.
